What is Geekbench 6?
Geekbench 6 is a cross-platform benchmarking tool from Primate Labs that measures processor and graphics performance using real-world workloads, such as image processing, machine learning and encryption tasks, rather than synthetic maths loops. Because it runs the same tests on macOS, iOS, Windows and Android, it's one of the few ways to compare an iPad, MacBook and PC on a level footing.
What is single-core score?
Single-core score reflects how fast one CPU core can work through a task on its own. It's the best indicator of everyday responsiveness: app launches, scrolling, web browsing and lightly threaded software all lean heavily on single-core speed, so this number matters most for how "snappy" a device feels.
What is multi-core score?
Multi-core score measures performance when a workload is spread across every available CPU core at once. It's the number to watch for heavier tasks like exporting video, compiling code or batch photo editing, and it scales with core count, so chips with more cores tend to pull ahead here even if their single-core speed is similar.
What is Metal score?
The Metal score comes from Geekbench's GPU compute benchmark, run through Apple's Metal graphics API. It measures how quickly the graphics chip handles parallel workloads such as image filters, video processing and on-device machine learning, and it's a useful stand-in for gaming and creative-app graphics performance, separate from raw CPU power.
History of Apple Silicon
Apple began its transition away from Intel processors in November 2020 with the M1 chip, bringing the same ARM-based, unified-memory architecture used in iPhone and iPad A-series chips to the Mac. This traded the traditional split of separate CPU, GPU and RAM for a single chip with shared high-bandwidth memory and dedicated efficiency and performance cores, dramatically improving performance-per-watt. Since then, the lineup has grown through the M2, M3, M4 and now M5 generations, alongside Pro, Max and Ultra variants for higher-end machines, while the A-series has continued to power iPad and, more recently, entry-level MacBook hardware.
